Get Connected

How to Play

The Objective

The goal of the game is to find hidden categories by grouping matching tiles together on the board.

1. Ways to Create a Game

  • Manual Input: Type your category names and items directly into the input boxes.
  • Block Import: Paste comma-separated text into the Block Import text box to fill everything automatically.
  • Built-in AI Generator: Enter a target level and focus to let Google's AI build a set for you directly inside the app.
  • External AI Prompt: Copy a perfect pre-made prompt into ChatGPT or Claude, and paste their output into the Block Import box.

2. Gameplay

  • Once you start, all the items you entered will be scrambled onto the grid.
  • The active team selects tiles they think belong in the same category. Once they have selected enough, click "Submit Guess".
  • If they are correct, the tiles will merge, reveal the category name, and the team will score points!
  • If they are wrong, they lose their turn and it automatically passes to the next team.

Setting Up Your Free AI Generator (1-Minute Setup)

You can use the built-in AI tool to generate games for you instantly. To enable this, you just need a free personal key:

  1. Go to aistudio.google.com/app/apikey and sign in with any standard Google/Gmail account.
  2. Click Create API Key and copy the generated text code.
  3. Open Get Connected, paste the code into the API Key field on the setup page, and it will save automatically to your browser.
