Creating Question Sets

The app requires a .csv file with exactly 12 columns in this specific order (including the header row):

Question_Type, Level, Sentence, Correct_Answer, Option_A, Option_B, Option_C, Option_D, Part_1_Discriminator, Part_2_3_Clue, Hint_3_Remaining_1, Hint_3_Remaining_2

Using AI to Generate Questions

You can easily generate completely new sets of questions by copying and pasting the prompt below into an AI tool (like Gemini or ChatGPT). Just update the text in brackets [ ] to target the specific level and language areas your class needs!

Generate a CSV set of [24] Use of English questions at [B2 / FCE] level. Please include an equal mix of Part 1, Part 2, and Part 3 questions, arranged randomly. [Optional: Focus the questions on the target language area: e.g., Travel vocabulary, Conditionals, Gerunds & Infinitives, Phrasal verbs]. Please output strictly as raw CSV text with no markdown blocks or extra conversational text. Use these exact 12 headers: Question_Type, Level, Sentence, Correct_Answer, Option_A, Option_B, Option_C, Option_D, Part_1_Discriminator, Part_2_3_Clue, Hint_3_Remaining_1, Hint_3_Remaining_2 Rules for generation: 1. Sentence must use '___' for the gap. 2. Option_A through Option_D are the 4 choices (For Parts 2 & 3, generate these to serve as the multiple choice hint). 3. Part_1_Discriminator applies only to Part 1 (e.g., 'Collocation', 'Meaning / nuance', 'Grammar pattern'). Leave blank for P2/3. 4. Part_2_3_Clue applies only to P2/P3 (e.g., 'Word type: Preposition', 'Word family: CARE'). Leave blank for P1. 5. Hint_3_Remaining_1 and Hint_3_Remaining_2 must be the correct answer and exactly one incorrect distractor from the 4 options. 6. Use British English spelling conventions.

Game Instructions & Setup

Mechanics: Teams select guesses using the input box, but only score or lose control when they lock in an answer. Incorrect locked-in answers instantly pass control to the next team.

Early Selection Bonus: Making an early guess pays off. If you select a correct guess at Stage 0, but wait for Stage 1 to Lock In, you score 8 points instead of 6. If you select at Stage 1, but wait for Stage 2 to Lock In, you score 5 points instead of 3. If you select at Stage 2, but wait for Stage 3 to Lock In, you score 2 points instead of 1.

Turn Order: The team highlighted in Orange on the scoreboard gets to choose the grid number. This order rotates perfectly each round, regardless of mid-round steals or curveballs.

Auto-Scoring vs Manual: Using the "Lock In!" button automatically checks the answer. (Note: For valid synonyms not in the answer key, teachers can use the Manual Override buttons to award points directly).
